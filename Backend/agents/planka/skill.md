# Planka

## โครงสร้างข้อมูล
- ระบบนี้เป็นบอร์ดคัมบัง เรียงจากบนลงล่างดังนี้: โปรเจกต์ > บอร์ด > ลิสต์ > การ์ด
- การ์ดมีงานย่อย (task) ป้ายกำกับ (label) และความคิดเห็น (comment) ได้

## เริ่มอ่านจากตรงไหน
- `getProjects` (GET /projects) คืนรายการโปรเจกต์ และบอร์ดทั้งหมดอยู่ใน `included.boards`
- `getBoard` (GET /boards/{id}) คืนลิสต์ การ์ด และป้ายกำกับทั้งหมดของบอร์ดในครั้งเดียว
- จะหาการ์ดตามชื่อ ให้อ่าน getProjects → getBoard ของบอร์ดที่เกี่ยวข้อง แล้วหาในผลลัพธ์

## กฎการลบของ Planka
- ลบโปรเจกต์ (`deleteProject`) ได้เฉพาะเมื่อโปรเจกต์ไม่มีบอร์ดเหลือ ถ้ายังมีบอร์ด ระบบจะตอบ 422 "Must not have boards"
- ก่อนลบโปรเจกต์ ให้อ่าน `getProjects` แล้วดู `included.boards` ที่มี `projectId` ตรงกับโปรเจกต์นั้น
  - ถ้าไม่มีบอร์ด: เรียก `deleteProject` ได้เลย
  - ถ้ามีบอร์ด: ห้ามเรียก `deleteProject` ให้บอกผู้ใช้ว่าโปรเจกต์มีบอร์ดอะไรบ้าง (บอกชื่อ)
    และต้องลบบอร์ดเหล่านั้นก่อน ถามผู้ใช้ว่าจะลบบอร์ดหรือไม่ ถ้าผู้ใช้ตกลง ให้ลบทีละบอร์ดด้วย `deleteBoard`
    (การ์ดและลิสต์ในบอร์ดจะถูกลบไปด้วย)

## ตารางสอบ
- ตารางสอบอยู่ในบอร์ดชื่อ "ตารางสอบ"
- การ์ด 1 ใบ = 1 วิชา, `dueDate` = เวลาสอบ, ป้ายกำกับ = ประเภทสอบ
- คำอธิบายการ์ดมีบรรทัด "ห้อง: ..." บอกห้องสอบ

## คำค้นที่ใช้กับ search_actions
ชื่อ action เป็นภาษาอังกฤษ เช่น card, list, board, project, label, task, comment
ตามด้วยกริยา create / update / delete / get
