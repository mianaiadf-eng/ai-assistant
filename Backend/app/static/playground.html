ทดสอบผู้ช่วย AI

กดปุ่ม 💬 มุมขวาล่างเพื่อเริ่ม ครั้งแรกจะถาม API key (ค่า APP_API_KEY ใน Backend/.env หรือ public_key ของ client playground)

หน้านี้ใช้ client playground ซึ่งไม่ได้ฝังในระบบใด ผู้ช่วยจึงขอให้ผูกบัญชีทีละระบบเมื่อจำเป็น (auth กลาง) · บัญชี Planka ทดสอบ: demo / demo (ดูผลจริงที่ localhost:3000) · ระบบทะเบียนจำลองรับทุกชื่อผู้ใช้/รหัสผ่าน
